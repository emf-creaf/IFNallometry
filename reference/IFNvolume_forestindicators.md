# Wrapper tree volume function for package forestindicators

Wrapper tree volume function for package forestindicators

## Usage

``` r
IFNvolume_forestindicators(x, province, ...)
```

## Arguments

- x:

  A data frame corresponding to plant_dynamic_input in package
  forestindicators

- province:

  A numeric code with Spanish province

- ...:

  Parameters not used

## Value

A vector of timber volumes per tree cohort (in m3/ha).
