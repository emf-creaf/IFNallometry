# Example datasets

Data sets given to illustrate input data structures.

## Format

Tree data corresponding to three forest plots. Data frame with 40 rows
(tree records) and columns:

- `ID`: Forest plot code, defined as the combination of province code
  and "estadillo".

- `Species`: Tree species code.

- `N`: Tree density (individuals per hectare) that the record
  represents.

- `DBH`: Tree diameter at breast height (cm).

- `H`: Tree height (m)
